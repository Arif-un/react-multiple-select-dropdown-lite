## Use it

Import the component and its stylesheet once, pass `options`, and read the selection from `onChange`. By default `onChange` gets the selected values joined by commas.

<Preview code={basicCode} title='Basic.tsx'>
  <Basic client:load />
</Preview>

Each option needs a `label` (string or JSX) and a unique string `value`. Pre-select with `defaultValue`, as a comma separated string or an array.

## TypeScript

Types ship with the package. `onChange` gets a `string`, or `MultiSelectOption[]` with `jsonValue`:

```tsx
import MultiSelect from 'react-multiple-select-dropdown-lite'
import type { MultiSelectOption } from 'react-multiple-select-dropdown-lite'

<MultiSelect options={options} onChange={(value: string) => {}} />
<MultiSelect jsonValue options={options} onChange={(value: MultiSelectOption[]) => {}} />
```

Also exported: `MultiSelectGroup`, `MultiSelectProps` and `MultiSelectValue`.
