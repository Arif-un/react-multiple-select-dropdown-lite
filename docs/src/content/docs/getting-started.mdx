React 18 and 19 are supported. The open menu is a popover: it needs the Popover API, in Chrome 114, Firefox 125 and Safari 17. Submenus open beside their title where the browser has CSS anchor positioning, else under it, in the menu.

## Use it

Import the component and its stylesheet once, pass `options`, and read the selection from `onChange`. It gets the selected values as an array, and their option objects as a second argument.

<Preview code={basicCode} title='Basic.tsx'>
  <Basic client:load />
</Preview>

Each option needs a string `label` and a unique string `value`, or any shape with [`getLabel` and `getValue`](../examples/#option-objects). Pre-select with `defaultValue`, an array of option values. It only sets the initial selection; to change the selection from outside, pass `value` instead ([controlled value](../examples/#controlled-value)).
