## CSS variables

The defaults live on `.msl-vars`, the wrapper of every dropdown. Override them on `.msl-vars` for all dropdowns, or add your own class for one. Keep `.msl-vars` in the selector: a lone class of yours ties with the defaults, so it only wins when its CSS loads later.

| Variable                         | Default                    | Controls                                      |
| -------------------------------- | -------------------------- | --------------------------------------------- |
| `--msl-input-width`              | `300px`                    | width                                         |
| `--msl-menu-max-height`          | `400px`                    | menu height before it scrolls                 |
| `--msl-font-size`                | `16px`                     | font size                                     |
| `--msl-line-height`              | `1.4`                      | line height                                   |
| `--msl-border-radius`            | `8px 8px 8px 8px`          | corner radius                                 |
| `--msl-active-menu-background`   | `white`                    | background while open                         |
| `--msl-active-menu-shadow`       | `0 2px 8px 0px #b1b1b1`    | shadow while open                             |
| `--msl-active-menu-radius`       | `var(--msl-border-radius)` | corner radius while open                      |
| `--msl-placeholder-color`        | `rgb(146, 146, 146)`       | placeholder text color                        |
| `--msl-border-color`             | `rgb(156, 156, 156)`       | border                                        |
| `--msl-hover-border-color`       | `rgb(80, 80, 80)`          | border on hover                               |
| `--msl-disabled-background`      | `rgb(246, 246, 246)`       | background when `disabled`                    |
| `--msl-chip-background`          | `rgb(238, 238, 238)`       | chip                                          |
| `--msl-chip-delete-background`   | `rgb(218, 218, 218)`       | chip delete button                            |
| `--msl-chip-delete-color`        | `rgba(0, 0, 0, 0.6)`       | chip delete icon                              |
| `--msl-button-hover-background`  | `lightgray`                | clear, arrow and chip delete buttons on hover |
| `--msl-option-hover-background`  | `rgb(233, 233, 233)`       | option on hover or keyboard highlight         |
| `--msl-option-active-background` | `#e6f4fa`                  | selected option                               |
| `--msl-option-active-color`      | `#0351ff`                  | selected option text                          |
| `--msl-option-disabled-color`    | `hsla(0, 0%, 0%, 0.3)`     | disabled option text                          |
| `--msl-group-title-background`   | `#fafafa`                  | group title                                   |
| `--msl-focus-color`              | `rgb(0, 119, 255)`         | keyboard focus outline                        |
| `--msl-menu-z-index`             | `9999`                     | open menu stacking                            |
| `--msl-background`               | `transparent`              | background while closed                       |
| `--msl-scrollbar-color`          | `rgba(0, 0, 0, 0.1)`       | menu scrollbar thumb                          |

```css
/* every dropdown */
.msl-vars {
  --msl-input-width: 100%;
}
/* one dropdown: <MultiSelect className='compact' /> */
.msl-vars.compact {
  --msl-font-size: 14px;
}
```

## Class names

State classes:

| Class                          | On      | When                                  |
| ------------------------------ | ------- | ------------------------------------- |
| `msl-disabled`                 | wrapper | `disabled`                            |
| `msl-limit-reached`            | wrapper | `limit` is reached                    |
| `msl-active` / `msl-active-up` | `.msl`  | menu is open, below / above the input |
| `msl-option-active`            | option  | selected                              |
| `msl-option-focused`           | option  | highlighted by the keyboard           |
| `msl-option-disable`           | option  | disabled                              |

Parts: `msl-wrp` (wrapper), `msl` (input box), `msl-chip`, `msl-chip-delete`, `msl-single-value`, `msl-input`, `msl-clear-btn`, `msl-arrow-btn`, `msl-options` (menu), `msl-option`, `msl-grp-title`.

A single option can carry its own `classes` and `style`.

The component's one inline style is `display: contents` on the chip wrapper, which keeps that box out of the layout with or without the stylesheet. Everything else is in the stylesheet: without it the markup is unstyled, and plain CSS overrides any of its rules.
