## Groups

Groups have `type: 'group'`, a `title` and `childs`, and can nest. Options themselves can't have `type: 'group'`. `emptyDataLabel` shows when a group has no options. Search looks inside groups.

<Preview code={groupsCode} title='Groups.tsx'>
  <Groups client:visible />
</Preview>

## Creatable values

With `customValue`, typing text that matches no option offers **Create "..."**. Enter or comma adds it; created values are listed under **Custom Values**.

<Preview code={creatableCode} title='Creatable.tsx'>
  <Creatable client:visible />
</Preview>

## Option objects

Options can be any shape: `getLabel` and `getValue` read them. `onChange` gets the selected objects back as its second argument. Values created by `customValue` are always `{ label, value }`. The fields `disabled`, `style`, `classes` and `type` keep their meaning in any shape.

<Preview code={optionObjectsCode} title='OptionObjects.tsx'>
  <OptionObjects client:visible />
</Preview>

## Controlled value

Pass `value` and update it from `onChange` to own the selection, for example to reset it or set it from elsewhere. `defaultValue` only sets the initial selection.

## Search in the menu

`searchInMenu` puts the search field at the top of the open menu. The closed control shows only the values, or `placeholder` when there are none, with no search placeholder next to the chips. `searchPlaceholder` labels the field. Single select and `disableChip` can then search with a value selected.

<Preview code={searchInMenuCode} title='SearchInMenu.tsx'>
  <SearchInMenu client:visible />
</Preview>

## Delete chips with their button only

Backspace in an empty search field removes the last chip. `deleteOnBackspace={false}` turns that off, so only a chip's delete button removes it.

<Preview code={deleteOnBackspaceCode} title='DeleteOnBackspace.tsx'>

</Preview>
