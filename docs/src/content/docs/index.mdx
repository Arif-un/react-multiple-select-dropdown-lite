## Features

<CardGrid>
  <Card title='Lightweight' icon='rocket'>
    About 4 kB gzipped. No dependencies besides React 18 or 19.
  </Card>
  <Card title='Search and create' icon='magnifier'>
    Filter as you type, or let users add their own values with `customValue`.
  </Card>
  <Card title='Groups' icon='list-format'>
    Nested option groups with their own empty state.
  </Card>
  <Card title='Accessible' icon='approve-check'>
    ARIA combobox and listbox, full keyboard support, SSR-safe ids.
  </Card>
  <Card title='Themeable' icon='setting'>
    CSS variables for sizes and colors, plain class names for everything else.
  </Card>
  <Card title='TypeScript' icon='document'>
    Types ship with the package; `onChange` is typed per `jsonValue`.
  </Card>
</CardGrid>
